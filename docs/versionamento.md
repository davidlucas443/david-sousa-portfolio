## Arquivos locais excluídos

`node_modules`, `dist`, `.npm-cache`, `.qa`, arquivos `*.local` e `*.tsbuildinfo` são ignorados. O lockfile npm e os assets originais utilizados no portfólio são versionados. A referência fornecida permanece preservada e versionada.

Uma busca prévia nos arquivos do projeto não encontrou os padrões de credenciais privadas, tokens GitHub/AWS ou JWT procurados. Credenciais de autenticação não foram gravadas em arquivos nem incluídas no histórico. As ferramentas auxiliares usadas para preparar o envio permanecem na pasta local ignorada `.qa`.

Esta etapa não configura hospedagem nem faz deploy do site.
